# Ilustracje MBG

Pięć poglądowych ilustracji SVG autorstwa Codex, utworzonych jako kod w ramach poprawy UI/UX z 4 października 2026. Są lekkimi schematami tematów: aktywności pamięciowe, język, praca, spotkania sąsiedzkie i wolontariat. Nie przedstawiają prawdziwych osób ani rzeczywistych produktów.

Logo właściciela i rysunkowy artwork landingu pozostają bez zmian. Ikony nawigacji nadal korzystają z niezmienionych kształtów Phosphor regular (MIT), złożonych w sprite przez `scripts/build-icon-sprite.mjs`; licencja znajduje się w `public/brand/Phosphor-LICENSE.txt`.
