# Przypadki oceny retrieval

1. Senior w Małopolsce potrzebuje transportu na rehabilitację — oczekiwane są rozwiązania transportowe lub asystenckie, nie rozwiązania edukacyjne.
2. Zgłoszenie spoza Małopolski — adapter aplikacji powinien odrzucić je przed wyszukiwaniem.
3. Problem bez podobnego rozwiązania — wynik może być pusty; nie wolno tworzyć fikcyjnej innowacji.
4. Kilka fragmentów jednej innowacji — prezentowana jest jedna rekomendacja z jej źródłem.
