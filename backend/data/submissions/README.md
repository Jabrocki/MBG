# Synthetic submissions

Ten katalog zawiera wyłącznie fikcyjne, syntetyczne zgłoszenia do wykorzystania w ocenie i testach AI.

- `synthetic_reports.md` nie opisuje prawdziwych osób, statystyk ani danych źródłowych.
- Zgłoszenia nie zwiększają liczby realnych zgłoszeń i nie są łączone z innowacjami.
- Wszystkie scenariusze dotyczą Małopolski, ale lokalizacja jest celowo ogólna.
- Embeddingi tego zbioru są zapisywane osobno przez importer AI wraz z hashem treści i konfiguracją modelu.
